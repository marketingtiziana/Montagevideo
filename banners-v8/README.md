Aucune icône : seul le wordmark FYNOVATES d'origine (`brand/wordmark-3x.png`).

- `output/` : PNG haute résolution, avec et sans signature.
- `mockups/` : aperçu dans une page de chaîne YouTube.
- `previews/` : aperçus TV, ordinateur, mobile.
- `comparison.html` : planche comparative.
- `concepts.mjs` : sources modifiables (textes, couleurs, tailles) ; `build.mjs` : export.

Modifier `concepts.mjs` puis lancer `node banners-v8/build.mjs` (ou `node banners-v8/build.mjs 4` pour un seul concept).
Polices attendues dans `banners/fonts/` : Montserrat, Inter, Source Serif 4 (OFL).
