# Sources photographiques

## Photographies de Tiziana

Shooting réel, dossier Google Drive « 📸PHOTOS Tiziana ». Fichiers dans `photographies/tiziana/` (19 photos, voir `index.json` pour les noms d’origine). Aucune retouche du visage ni de la silhouette.

- `photographies/etalonnees/` : mêmes photos, étalonnage chaud uniquement.
- `photographies/detourages/` : détourages réalisés à partir de ces photos (rembg, modèle u2net_human_seg).
- Les décors du livre sont des **photomontages de simulation** : un détourage réel placé dans un décor reconstitué. Ils montrent un cadrage, pas une photo prise dans ce décor.
