# Découpage en chapitres — scène motion design (zone haute 1080×1060) — v3 « produit »

Direction artistique : **fond blanc uni**, langage d'interface sobre et premium : fenêtres macOS, iPhone, iPad, notifications, modales, toasts, graphiques, tableur. Palette encre `#0E1230`, gris `#6B7280`, bleu électrique `#4353FF` ; vert `#30D158` uniquement pour les validations, corail `#FF6B6B` uniquement pour les alertes. Aucune forme décorative multicolore.

Effets permanents : les appareils « respirent » (tilt 3D ±4°), halos lumineux doux sur les beats, anneaux fins d'onde de choc (bleu/vert/rouge selon le sens), micro-shake de l'écran sur les impacts, reflets de verre qui balayent les écrans, transitions zoom-blur entre chapitres (jamais de cut sec).
