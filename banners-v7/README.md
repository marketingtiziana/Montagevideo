## Fichiers
- `output/` : PNG haute résolution 2560 × 1440, avec et sans signature.
- `mockups/` : aperçu dans une page de chaîne YouTube.
- `previews/` : aperçus TV, ordinateur, mobile.
- `comparison.html` : planche comparative.
- `src/*.html` : sources de chaque bannière (HTML/CSS/SVG), modifiables et ouvrables dans un navigateur.
- `concepts.mjs` : compositions paramétrées (textes, tailles, couleurs) ; `build.mjs` : export PNG.

## Modifier et régénérer
1. Changer un texte, une couleur ou une position dans `concepts.mjs`.
2. `node banners-v7/build.mjs` (ou `node banners-v7/build.mjs 3` pour le seul concept 3).

Polices : Montserrat, Inter et Source Serif 4 (Google Fonts, licence OFL), attendues dans `banners/fonts/`.
